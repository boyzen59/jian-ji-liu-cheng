# 苹果化材质、排版与运动

本规范把 Apple 式清晰层级、半透明材质和物理运动移植到 Soft Signal。颜色只使用 `fixed-style.md` 的暖白、深棕和橙色，不新增品牌色。苹果化指材质、排版、空间关系和运动品质，不指复刻任何产品界面。

## Apple 逻辑门禁

不要把“Apple”缩减为圆角、毛玻璃和 SF 字体。每个程序化 Scene 必须先写清：`purpose`（这一镜为何存在）、`focal_hierarchy`（第一至第三注意点）、`spatial_origin`（从哪个可见主体/前一镜锚点产生）、`material_response`（材质厚度为何匹配层级）、`continuity`（入退如何沿同一路径或交给转场）、`settle_state`（何时落定、读多久）和 `delight`（克制触感，没有则写 none）。缺任一项不得进入动效实装。

- 目的先于装饰：每个物件都要帮助理解、定位、证据阅读或情绪关系。
- 层级先于数量：第一注意点最先响应，辅助项随后建立；简洁不是让人物或图片周围空无一物。
- 空间必须可预测：组件从人物、图片证据、上一结论或路径节点产生；不得从无来源的屏幕中心弹出。
- 运动保持连续：入退同路径、速度无断裂、落定可读。默认无回弹；只有明确惯性才允许一次轻回弹。
- 材质表达关系：大面板更厚，小标签更轻；玻璃在内容上方建立结构，不把证据整体磨糊。

## 不可协商的目标

- 先读内容，再感知玻璃，最后才注意背景动画。
- 含文字的程序化镜头默认使用一层局部毛玻璃信息面；真实影像和主证据固定 `media_body_blur_px=0`，不整屏磨砂，不用模糊延展补画布。
- 玻璃后的动画、图案或影像必须若隐若现：观众能感知方向、色块和节奏，但不能在阅读文字时辨认细碎背景文字。
- 所有文字保持完全不透明；禁止通过降低文字 opacity 营造轻盈。
- 一个画面最多两个半透明平面；禁止浅玻璃叠浅玻璃、卡片套卡片和等权玻璃宫格。

## 四层画面模型

1. `background`：真实素材或暖白底，不强制调色。
2. `ambient`：低对比动画、图案或光影；抽象背景常态 opacity `0.08–0.18`，局部峰值不超过 `0.24`。
3. `glass`：承载标题、字幕、数据和控件感信息；按面积使用 thin、regular 或 thick。
4. `content`：完全不透明的文字、图标和关键证据，始终处于最高视觉对比层。

文字/证据背后的环境运动优先缓慢位移、尺度、焦点、光影、渐变、轻粒子或柔和液态变化；穿过主体安全区时，位移不超过画幅短边的 `3%`，尺度通常在 `1.00–1.06`。主体外侧可有更明显的节奏、粒子、goo 或形状运动，但不能用高对比边缘、强闪或高速路径把视线从主体拉走。经过明确时机设计并通过主体保护检查的 ambient 动效可计入观看体验覆盖。

## 毛玻璃选择

| 材质 | 场景 | 建议参数 |
|---|---|---|
| `glassThin` | 标签、小按钮、短数字 | 暖白 52%–60%，blur 16–20px，轻阴影 |
| `glassRegular` | 字幕、标题、普通信息卡 | 暖白 66%–74%，blur 24–28px，中等分离 |
| `glassThick` | 复杂背景上的长文、图表结论 | 暖白 80%–88%，blur 32–40px，较深阴影 |

- 面积越大，材质越厚；背景越复杂，填充不透明度和 blur 越高。
- 使用暖白 tint、白色受光边缘和深棕低透明阴影；不引入冷蓝玻璃。
- 玻璃出现时同步建立 blur、轻微 scale 和阴影，不只做 opacity 淡入。
- 若 `backdrop-filter` 不稳定，复制背景层并裁进面板，使用确定性的 `filter: blur(...)`；保持相同 token。
- 真实资料作为主证据时，玻璃只能放在空白安全区或局部字幕区，不覆盖需要阅读的资料原文。

## 字体清晰度

- 主字体优先系统字族：SF Pro 可用时使用 SF Pro，不可用时回退到 `-apple-system`、`BlinkMacSystemFont`、`Helvetica Neue`；中文优先 `PingFang SC`。
- Lora 只用于短标题、引文或编辑性章节字样，不用于玻璃上的长正文和小字。
- 大标题使用负字距，正文接近 `0`，小字使用轻微正字距；不要给所有字号套同一 tracking。
- 玻璃上的正文至少 500 weight，小字至少 600 weight；正文行高约 `1.45–1.6`。
- 正文/字幕目标对比度至少 `4.5:1`；大字至少 `3:1`。橙色只承担大号字幕、关键词和状态，不承担小号长正文。
- 2560×1440 从视频字号起调：章节/英雄标题 156–220px，主结论 104–148px，h1 88–112px，h2 64–80px，正文/卡片 42–54px，辅助说明 32–40px，来源元数据至少 26px。不得把网页 14–20px 字号直接搬进成片。
- 右侧信息面默认竖排：标题、要点、进度/箭头、来源自上而下建立；时间也是层级，最重要的总结先出现。
- 在背景最亮、最暗、最繁忙和运动峰值帧分别检查可读性。必要时升级玻璃厚度，不给文字添加粗黑描边。

## Apple 式运动

- 默认使用接近临界阻尼的 spring，不弹跳。Remotion 建议：`{mass: 1, stiffness: 170, damping: 26}`。
- 柔和大面板使用 `{mass: 1, stiffness: 130, damping: 23}`；快速小元素使用 `{mass: 1, stiffness: 220, damping: 30}`。
- 只有甩动、抛出或明确惯性语义允许轻微回弹，可使用 `{mass: 1, stiffness: 170, damping: 21}`，且只一次。
- 入场和退场沿同一路径，缩放原点来自触发物或内容锚点；不得无来源地从画面中心弹出。
- 主体先响应，辅助层随后建立；落定后保留至少 `0.5–1s` 清晰阅读帧。
- 快速运动只动画 transform、opacity 和必要的 blur；环境循环必须由当前帧确定、在有限 Scene 内可停止，避免全屏随机抖动、运行时随机和跨主体的无休止呼吸。

## Remotion / HyperFrames 实装

- 每章 `chapter_title` 使用全屏超大双语标题，2560×1440 从约 156–220px 起调并铺满主要视觉区；先建立空间和材质，再建立标题、要点/逻辑框架，最后保留阅读落定。
- 开场真人全屏最多 15 秒；开场后人物仅以直径约 360px（340–380px）圆形小窗出现，默认固定右下并抬高到字幕排除区上方。禁止中段全屏；只有最终总结可回到全屏并持续到实际最后一帧。开场/结尾说明动效同样逐镜比较 Remotion 与 HyperFrames，不固定引擎。
- 普通/AI 图片与视频使用清晰原画全屏舞台；图片运动按语义变化，视频完整自然播放。只有上方文字使用局部玻璃。`archive_evidence` 与 `book_evidence` 使用简中＋英文来源区＋大幅清晰证据图，证据在屏时禁止动态说理。

- 从统一 Soft Signal token 读取玻璃、字体、对比和 spring；禁止组件内自创近似参数。
- 每个含文字程序化 Scene 在 spec 中声明 `material`、`background_visibility` 和 `legibility`。
- 文字在玻璃达到约 70% 的材质强度后再完全显现，避免先出字、后补底。
- `background_visibility: faint` 为默认；只有背景本身是证据时使用 `evidence`，此时把文字移到独立安全区。
- 为透明度降低和高对比模式保留可切换 props：关闭 blur 时提高面板填充；高对比时增加边缘分离，不改变主题色。
- 2560×1440 底部固定保留 220px 字幕排除区；卡片、人物小窗、进度条、箭头和关键文字的底边不得进入。即使字幕最终外挂，也不得取消此区。
- HyperFrames 先构建 hero frame，再按 `build → breathe → resolve` 编排；全部可见元素有入场，场景转场承担前一场退出。Remotion 也必须有可见的媒体推移、缩窗、蒙版、标注或空间接力，不得只做静态容器。

## 验收

- 缩略到 25% 仍能一眼找到主标题、主数据或主证据。
- 25% 缩略图仍能看出第一、第二注意点与它们的空间关系；若只剩玻璃质感而看不出叙事路径，判定未苹果化。
- 暂时隐藏文字时，玻璃后的背景仍可感知；恢复文字后，背景不与任何字形竞争。
- 玻璃边缘、文字和背景在运动中无闪烁、banding、脏边或明显色偏。
- 每镜至少保存：背景最繁忙帧、材质建立帧、文字落定帧。
- 另保存字幕排除区叠加检查帧、开场/结尾人物双侧组件帧和相邻动效签名对照；连续同签名直接失败。
- 若只能在静止帧读清、运动中读不清，则该镜头不通过。
