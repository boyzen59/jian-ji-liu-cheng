# Lottie、D3、Blender、Manim 扩展动效路由

五源统一 Remotion 资料库先提供运动语法与组件候选；扩展引擎只在内容形态确实匹配时加入。Remotion始终拥有总时间线。

## 快速选型

| 内容需要 | 首选 | 典型例子 | 回退 |
|---|---|---|---|
| 小型矢量解释件、图标状态 | Lottie | 箭头、循环机制、图标变形 | SVG + Remotion |
| 排名、时间序列、地图轨迹、网络关系 | Remotion + D3 | GDP 排名竞赛、台风路径、人口迁移 | Remotion 原生 SVG/Canvas |
| 真实材质、产品结构、复杂灯光/镜头 | Blender → Remotion | 汽车拆解、机械剖面、产品级 3D | 2.5D 分层或 `@remotion/three` |
| 数学/科学结构与逐步推导 | Manim → Remotion | 公式、几何、算法、状态机、物理过程 | SVG/D3/Remotion |
| UI、标题、流程、轻量图表、图片问题要点 | HyperFrames + 统一 Remotion 资料库 | 信息段、列表、对照、进度/箭头、图片全屏毛玻璃说明 | Remotion 原生图形；不把普通图片缩进 PPT 卡 |

每个扩展 Scene 写入：`engine`、`why_this_engine`、`data_or_asset_source`、`duration_seconds`、`fps`、`text_review_id`、`fallback`、`qa_frames`。

## Lottie

- 只使用本地 JSON/`.lottie` 资产，不在渲染时请求网络。
- 在 Remotion 中由当前帧确定进度；禁止自主 CSS 无限循环。
- 首次使用先检查尺寸、总帧数、帧率、字体/文字、外链图片和表达式。
- Lottie 中若含任何中文或英文，先纳入《动效文字执行手册》；能删掉文字并由 Remotion 叠字时优先删。
- 表达式可能导致非确定性或闪烁；测试失败即转为 SVG/PNG 序列，不赌终渲。

## Remotion + D3

D3 负责数据计算，Remotion 负责时间：

- 用 D3 计算 scale、axis、shape、geo projection、排序和插值；不要启动 `d3-transition` 自己跑时钟。
- 每帧从 `useCurrentFrame()` 与 `fps` 算归一化时间，再得到当前数据状态。
- 排名竞赛必须稳定排序；数值相同时使用固定 ID 作第二排序键，避免抖动。
- GDP/人口/价格等数据保留来源、单位、名义/实际口径、币种、基期、缺失值和修订日期。
- 台风轨迹保留时间戳、经纬度、强度、资料机构与投影；路径不能为了好看穿越错误边界。
- 坐标轴、图例、排名标签和数字都属于待审文字，先走文字门禁。
- 复杂阅读期间背景动效降到 faint 或停稳；排名变化、轨迹推进和口播结论对齐。

## Blender → Remotion

- Blender 只生成独立 3D pass，不管理旁白、外挂字幕或全片节奏；有兼容 GPU 时优先 GPU 草稿/生产渲染，先做代表段稳定性测试。
- 先做低采样 animatic，确认构图、相机、焦距、材质和运动，再做生产渲染。
- 需要透明合成时输出带 alpha 的图像序列或中间编码；需要调色时优先高质量中间格式。最终 H.264/Rec.709 只在 Remotion/FFmpeg 总交付阶段生成。
- 固定随机种子、物理缓存、色彩管理、帧率和帧范围；记录 Blender 版本与资产许可。
- 产品级镜头不得假装真实厂商 CAD 或设计细节；没有权威资产时标为示意。
- 3D 背景在毛玻璃后保持若隐若现，文字和人物安全区优先。

## Manim → Remotion

- 命中时读取并遵循 `manim-video` Skill；只移植其教学结构，不覆盖本 Skill 的 Soft Signal 色调、字体审阅和 2K60 主规格。
- 先写误解点、Aha 时刻、逐步建立顺序和每步停留，再写代码。
- 公式、变量、单位、中英文标签全部进入文字审阅。
- 草稿低质量快速渲染；生产片段输出 2560×1440、60fps 或可无损适配到该规格的中间文件。
- Manim 片段固定入点、出点和落定帧，Remotion 负责配音时间同步、已审双语解释文字、毛玻璃信息面和总合成；连续字幕仍外挂。

## 氛围与装饰边界

避免没有功能说明的装饰画面。`ambient` 可以保留，但必须至少承担一种明确体验功能：建立时代/地点氛围、提供触感、形成节奏呼吸、增加空间深度或提示章节能量。

`ambient` 记录 `visual_experience_gain` 与 `why_keep`。若删掉后体验无损，或它遮挡/扭曲/误导/抢夺文字、人脸、手势、数据、证据或关键 UI，就删除、暂停、降强度或换路径。
